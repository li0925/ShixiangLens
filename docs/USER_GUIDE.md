# 拾像 Lens 4.1

截图 · 标注 · 识字

空天遥感数学交叉技术创新中心

品牌图标：湘大三拱门与空天轨道，采用已选定的 C 方案。简明说明见同目录《使用说明.txt》，软件托盘菜单也可随时打开。

参考 Snipaste 的截图、贴图和标注交互，内置 RapidOCR 3.10.0 + PP-OCRv6 Small 离线文字识别。独立 Windows 应用，无需安装 Python。没有使用 Snipaste 的程序代码或图标。

## 开始使用

先退出 Snipaste 和旧版 SnapText，避免 F1/F3 或其他全局热键被占用。运行 `拾像 Lens.exe`。主说明窗口关闭后仍驻留托盘。托盘右键可打开首选项、管理分组、找回隐藏贴图、取消鼠标穿透、退出。

| 操作 | 默认按键 |
| --- | --- |
| 开始截图 | F1 |
| 将剪贴板内容贴到桌面 | F3 |
| 直接框选文字识别 | Ctrl+Alt+O |
| 截图选区确认并复制 | Enter / 双击选区 |
| 截图选区直接贴图 | F3 / 工具栏“贴图” |
| 取消截图 / 清除当前选区 | Esc / 右键 |
| 截图时复制光标像素颜色 | C |
| 截图选区移动 1 个界面像素 | 方向键 |
| 截图选区右边/下边微调 | Shift+方向键 |
| 回顾选区历史 | , / . |

F1 截图时，鼠标悬停可吸附窗口或原生子控件区域；拖动可自由框选。选区建立后不会立即消失，可以移动和拉动边缘/八个控制点，再确认复制或贴图。像素放大镜显示当前位置颜色。

首选项“热键”可设置自定义快捷键；“常规”可设置主题色、界面字体、字号、通知栏图标和开机启动；“截图”可关闭区域检测和放大镜；“贴图”可设置工具栏、阴影和自动备份恢复。开机启动默认关闭，只有主动勾选并保存时才写入当前用户启动项，不需要管理员权限。

## 桌面贴图

默认只显示图片，减少边框和工具栏干扰。普通拖动移动位置，右键查看完整菜单。

| 操作 | 按键 / 入口 |
| --- | --- |
| 展开/收起标注工具栏 | 空格 |
| 显示缩放 | 滚轮 / + / - |
| 调整透明度 | Ctrl+滚轮 / Ctrl+加减 |
| 顺/逆时针旋转 | 1 / 2 |
| 水平/垂直翻转 | 3 / 4 |
| 隐藏贴图 | 左键双击 / Esc |
| 缩略图与恢复 | Shift+左键双击 |
| 复制图片 / 保存图片 | Ctrl+C / Ctrl+S |
| 贴图取色 | 按住 Alt 移动，C 复制颜色 |
| 关闭贴图 | Ctrl+W |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |

右键可设置置顶、锁定、鼠标穿透、分组、透明度、裁剪和图像处理。鼠标穿透后，可从托盘“取消所有鼠标穿透”恢复操作。托盘分组菜单可只显示指定分组。

F3 支持图片、图片文件、纯文本、HTML 文本和 #RRGGBB 等颜色内容。HTML 资源只在本地绘制，不加载远程图片。静态图片支持 PNG/JPG/BMP/WebP/TIFF/ICO 等 Qt 可读格式。可打开或拖入图片，GIF 文件支持动画播放；播放中滚轮调速，1/2 暂停并切换帧，开始标注或 OCR 时冻结当前帧。GIF 保存/备份为当前静态帧，不导出编辑后的动画。

## 标注和识字

按空格显示紧凑的图标工具栏。可选择矩形、椭圆、直线、箭头、画笔、文字、马克笔、马赛克、高斯模糊和橡皮擦；下方色板和滑条直接调整颜色、粗细/文字大小。橡皮擦按选区移除相交标注，保留原图。撤销/重做支持最近 30 步。

右键“识别整张图片”识别全图；Ctrl+拖选，或工具栏“识字”，识别局部区域。文字结果仍在当前贴图下方展开，可编辑、复制、保存 TXT 或收起。导出图片不包含文字结果面板和 OCR 位置框。

模型随程序打包，识别图片不上传，启动后后台预加载。首次加载仍需几秒钟。中英文样图预热后约 0.1 秒，复杂截图的速度和准确率取决于文字量和画质。手写字、艺术字、复杂表格需人工校对；输出为纯文本，不恢复原文档结构。

## 自动备份与恢复

自动备份默认开启，可在首选项“贴图”关闭。贴图内容在修改后延迟保存，正常退出也会保存；下次启动恢复图像、位置、缩放、透明度、分组和显示状态。备份最多 30 张，图像保存为平面 PNG，恢复后不包含旧的撤销历史和 GIF 播放状态。

设置和备份保存在当前用户本机应用数据目录 `SnapText/preferences.json`、`SnapText/session/`（Qt AppLocalDataLocation）。关闭备份选项不会自动删除已有备份文件。图片始终留在本机，不上传。

## 范围

支持各显示器单独框选及高 DPI 图片映射；一次跨越多个显示器的选区暂未实现。自动区域检测基于 Windows 窗口/原生子控件，网页内部、自绘 UI 的任意元素不能保证逐个识别。阴影显示也受 Windows 窗口合成设置影响。这一版对齐常用操作，不宣称已完全复刻 Snipaste 的所有细节。

